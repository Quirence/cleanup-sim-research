# Проверка первого слоя режимных показателей

На чистом commit `392b6b04c43373c83cd91db3a7f34dfd8c55d5e8` проверены
журналирование и офлайн-анализ показателей из [определений v1](regime_metrics.md).
Полный набор тестов: **140 passed** (132 прежних + 8 новых).

Перед исполнением зафиксирован smoke: strong_drift, nominal, seed 300, путь 60 м,
время 120 с; adaptive_mission, belief_horizon и oracle_current_physics. Это
три технических запуска на уже просмотренном development seed. Параметры
алгоритмов и физики не подбирались, финальные seed не использовались.

```powershell
python -m cleanup_sim_v2.run_experiments --seeds 1 --seed-start 300 --scenarios strong_drift --modes adaptive_mission belief_horizon oracle_current_physics --max-path-m 60 --tmax-s 120 --save-runs --out-dir out/audit/regime_metrics_smoke_2026-09-08
python -m cleanup_sim_v2.analyze_regimes --run-dirs out/audit/regime_metrics_smoke_2026-09-08/runs --out-dir out/audit/regime_metrics_smoke_analysis_2026-09-08
python -m cleanup_sim_v2.analyze_regimes --run-dirs out/audit/reproducibility_control_2026-09-07/repeat1 --out-dir out/audit/regime_metrics_legacy_analysis_2026-09-08
```

Повторные исполнения должны использовать новые выходные каталоги. Команды
зафиксированы как точная история выполненного контроля, не команда перезаписи.

Результаты проверки:

- Все три новых запуска остановлены по пути; каждый содержит два назначения
  участков и снимки схемы v1 на 100% этих событий.
- Для всех трех новых строк найдена совместимая пара с oracle. Совпадают полная
  физическая конфигурация, seed и clean provenance; это проверка соединения данных,
  а не содержательный вывод о величине разрыва на короткой миссии.
- Четыре старых запуска `d92b496` разобраны с сохраненной конфигурацией и проверкой
  хешей. Снимков в них нет: динамические величины неизвестны (`NaN`), число снимков
  равно нулю. В этом входном наборе нет oracle, и gap также неизвестен.
- Проверены хеши входных манифестов и выходных таблиц обоих анализов. Анализаторы
  зафиксировали чистый `392b6b0` и фактическое окружение.
- Тест переключает только функцию снимка на пустую и сравнивает одинаковую
  конфигурацию/seed: summary, временной ряд, старые колонки событий, карта и позиции
  объектов совпадают точно. У функции снимка нет доступа к RNG и истинному полю.
- Формулы проверены на заданных длинах/временах/ошибках, границе акватории,
  отсутствии свежих tracks/массы карты/пройденного пути, цензурированных участках,
  несовместимых и дублированных oracle-парах. Отрицательный gap не обрезается.

Доказательства: [evidence/regime_metrics_2026-09-08](evidence/regime_metrics_2026-09-08/).
Архив содержит новые сырые журналы и анализы, inventory — SHA-256 каждого файла.
После упаковки каждый файл прочитан из архива и проверен. Старые сырые журналы
уже сохранены в архиве контроля воспроизводимости и не дублируются.

Пункт 2 плана выполнен как **измерительный слой v1**: у требуемых групп показателей
есть определения, единицы, источники, обработка недоступных данных и тесты.
Представление риска — отношение времен/сноса, не вероятность; локальная площадь
приближена сеткой; длительность очереди номинальная; средние состояния зависят от
политики. По этому smoke не строилась режимная карта и не выбирался алгоритм.

Следующий содержательный этап — заранее спроектировать второй слой чувствительности:
независимые уровни факторов, основные исходы, повторения, критерии валидности и
анализ граничного накопления. Историческая причина 143/128 остается открытой;
неопределенные серии коллеги не становятся финальными доказательствами.
