# Контроль воспроизводимости 7 сентября 2026

Протокол фиксируется до запуска. Машиночитаемая версия: [JSON](reproducibility_control_protocol_2026-09-07.json).

Восемь последовательных запусков в отдельных процессах: `strong_drift`, nominal,
`adaptive_mission` и `belief_horizon`, seed 300 и 301, по два повтора. Путь 3000 м,
время 16500 с. Эти seed уже просмотрены; бюджет остается диагностическим.
Цель — проверить повторяемость текущей версии, а не выбрать параметры или победителя.

Перед серией: полный pytest, чистый commit с кодом и протоколом. Фиксируются
полный commit, SHA-256 исходных файлов, Python, установленные библиотеки, сборка
NumPy, генератор PCG64 и доступные настройки вычислительных потоков.
Манифест сохраняет конфигурацию целиком и хеши результатов. После серии
проверяются неизменность версии и хеши исходных CSV/манифестов коллеги.

```powershell
python -m scripts.check_reproducibility --out-dir out/audit/reproducibility_control_2026-09-07
```

Каталог должен быть новым. Исполнение при грязном дереве запрещено. Повторы
сравниваются побайтово по summary, config, events, series, конечной карте и
позициям объектов. При расхождении CSV записывается первая различающаяся ячейка
и контекст события. Изменение происхождения кода/окружения, сбой процесса,
потерянный файл или нарушение его целостности означают непрохождение контроля.
Все результаты сохраняются, исключать неудобные запуски нельзя. Причины остановки
должны совпасть; неожиданный предел времени требует разбора, а не удаления строки.

С историей сравниваются все доступные общие физические summary-поля (для float
rtol=atol=1e-12 только из-за сериализации). Для adaptive используется AFTERFIX
trace, для belief — baseline до ревизии; совпадение config hash проверяется
отдельно. Несовпадение хеша не является тестом повторяемости одинаковых условий.
События коллеги не закоммичены, поэтому первое историческое расхождение событий
не может быть вычислено. Различие зависимостей и незакоммиченного кода остается
гипотезой до получения исходного окружения/diff или отдельного причинного опыта.

Успешная серия закрывает локальную повторяемость на данной контрольной матрице.
Она не доказывает переносимость между ОС/версиями библиотек и не восстанавливает
историческое происхождение 143/128. Старые серии остаются диагностическими;
новые исследования используют проверенные чистые версии. Финальный прогон
остается запрещенным до последующих этапов действующего плана.
