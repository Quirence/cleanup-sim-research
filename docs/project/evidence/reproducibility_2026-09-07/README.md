# Воспроизводимость: контроль 2026-09-07

См. [полный отчет](../../reproducibility_control_report_2026-09-07.md).

- `initial_control.tar.gz`: восемь запусков на чистом `d92b496`.
- `auc_followup.tar.gz`: два запуска на чистом `06fc57e` после исправления AUC.
- `*_archive_inventory.json`: SHA-256 архива и каждого содержащегося файла;
  каждый файл проверен чтением из созданного архива.
- `initial_report.json`, `followup_report.json`: побайтовые сравнения повторов,
  сравнения с историческими CSV, проверка неизменности исходных таблиц.
- `*_provenance.json`, `*_protocol.json`: полный снимок среды и протокол.
- `auc_reanalysis.json`: изменение AUC при перестановке одинаковых координат
  пути и проверка неизменности физических событий между версиями.

Побайтовые оригиналы находятся внутри архивов. Просмотровые JSON могут быть
нормализованы Git по окончаниям строк. Архивы распаковывать в новые каталоги,
сохраняя вложенные `repeat1/` и `repeat2/`; не перезаписывать историю.

Все материалы диагностические. Они подтверждают локальную повторяемость
проверенных конфигураций, но не восстанавливают отсутствующий dirty diff,
окружение и события коллеги; историческая причина 143/128 остается открытой.
