# Контроль измерительного слоя, 2026-09-08

См. [отчет](../../regime_metrics_validation_2026-09-08.md) и
[формулы](../../regime_metrics.md).

`regime_metrics_control.tar.gz` содержит три новых коротких запуска на чистом
`392b6b0`, их анализ и анализ доступности данных четырех старых trace.
`archive_inventory.json` содержит SHA-256 архива и всех файлов; целостность
проверена чтением каждого файла после упаковки.

CSV/JSON рядом — копии для просмотра; архив хранит исходные байты независимо
от нормализации окончаний строк Git. `verification.json` фиксирует покрытие
снимками, совместимость oracle, недоступность старых динамических состояний
и проверку хешей. Результаты не предназначены для сравнения качества алгоритмов.
